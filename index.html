Estoque geral de materiais

Cada linha é o estoque de um material dentro de um item específico — mesmo que o nome se repita em outra receita, os valores são independentes.
MaterialItemEstoque deste item
Como funciona: quando um material (ex.: Crafted Leather) aparece em mais de uma receita, cada item tem seu próprio contador — alterar o estoque de um não afeta o outro. Só o administrador altera os valores; os demais membros só visualizam.
